# src/Support —— 通用工具

放**不碰 IO、也不含业务规则**的小工具：地址格式化、随机数、序列化辅助。

## 和 Domain 的区别

| | Domain | Support |
|:--|:--|:--|
| 含业务规则 | 是 | 否 |
| 换个游戏还能用 | 不能 | 能 |
| 例子 | `Battle::resolve()` | `Ids::next()`、`Fmt::duration()` |

## 典型文件

```
Support/
├── Ids.php          自增/雪花 id
├── Fmt.php          数字、时长、金额的显示格式
└── Rand.php         可 seed 的随机（测试需要可复现）
```

## 一个提醒

这里的代码会被到处引用，所以**改动的影响面最大**。放进来之前先问一句：
"这东西真的跨域通用吗？" 只有一个模块用的话，就留在那个模块里。
